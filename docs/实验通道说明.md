# 实验通道说明

## 为什么需要它

目标安装包体积很大，一次「重建 → 签名 → 推送 → 安装」的成本远高于改几行代码。

因此把客户端改造成两段式：

```
包内固定：引导 dex + 一个运行时配置项
      ↓ 启动时从应用私有目录加载
随时替换：lab.dex + liblab.so（各约几十 KB）
```

迭代成本从十几分钟降到几十秒。

## 一、组成

| 文件 | 位置 | 作用 |
|---|---|---|
| `ProxyApp` | `inject/src/com/akpatch/` | 代理入口，在 attach 阶段拿到 Context |
| `Bootstrap` | 同上 | 加载 `lab.dex`，反射调用 `Lab.start()` |
| `Lab` | `lab/src/com/akpatch/` | 命令循环、SDK 侧改写、输出写文件 |
| `LabNative` | 同上 | native 接口声明 |
| `labl.c` | `lab/native/` | il2cpp 枚举、inline hook、URL 改写、探针 |

## 二、构建与部署

```bash
lab/build_lab.sh        # 产物：build/out/lab.dex、build/out/liblab.so
```

部署到调试机（需要 root）：

```bash
scp -F ~/.ssh/config build/out/lab.dex build/out/liblab.so phone:/data/local/tmp/
ssh -F ~/.ssh/config phone 'D=/data/data/<package>/files; \
  cp /data/local/tmp/lab.dex /data/local/tmp/liblab.so $D/; \
  chown root:root $D/lab.dex $D/liblab.so; chmod 644 $D/lab.dex $D/liblab.so'
```

### 权限上的坑

- dex 必须 root 所有且不可写（644）；可写目录会被运行时拒绝加载；
- SELinux 上下文需与应用私有目录一致；
- `.so` 先复制到 `code_cache/` 再加载。

## 三、三个交互文件

| 文件 | 时机 | 说明 |
|---|---|---|
| `files/ak_boot` | 每次启动执行一次 | 常驻探针 / 改写规则 |
| `files/ak_cmd` | 运行中随时 | 一次性命令，执行后清空 |
| `files/ak_out` | — | 命令输出与日志（追加写） |

## 四、命令分类

> 具体参数格式见脚本源码；这里只说明能力划分。

### 4.1 只读 / 枚举

| 类别 | 说明 |
|---|---|
| 基址查询 | il2cpp 基址（为 0 表示运行时未就绪） |
| 类枚举 | 按名字过滤导出类名 |
| 方法导出 | 类 + 方法 + RVA |
| 字段导出 | 字段名 / 类型 / 偏移 |
| 方法定位 | 按命名空间、类名、方法名、参数个数精确定位 |
| 内存扫描 | 在进程内搜索字符串 |
| 配置对象读取 | 读运行时配置单例的字段 |

### 4.2 改写型（会改变行为）

| 类别 | 说明 | 风险 |
|---|---|---|
| URL 主机改写（多槽位） | 每个目标独立跳板，改写网络调用的主机部分 | 低 |
| 固定返回值 | 让方法直接返回指定字符串/整数 | 中（整函数替换） |

### 4.3 打点型（记录后调原函数）

| 类别 | 说明 | 风险 |
|---|---|---|
| 单目标探针 | 打印参数与返回值 | 中 |
| 多目标探针 | 多槽位并行 | 高：短方法会崩 |
| 方法指针替换 | 替换 `MethodInfo->methodPointer` | 对直接调用无效 |

## 五、排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 无 lab 日志 | dex 未加载 | 检查权限 / SELinux 上下文 |
| 启动即闪退 | 探针打在短方法上 | 清空启动脚本后重启 |
| 基址为 0 | Unity 尚未加载 il2cpp | 正常，命令会自动等待就绪 |
| 符号缺失导致库加载失败 | 引用了未定义符号 | 先修好 native 库，否则其余改写一并失效 |
| 命令无反应 | 应用在后台被冻结 | 切到前台再写命令文件 |

## 六、一条龙脚本

`lab/run_flow.sh`：强杀 → 启动 → 轮询窗口焦点 → 按固定坐标点击 → 抓日志与截图。坐标与设备别名可用环境变量覆盖。
